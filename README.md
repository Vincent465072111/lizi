# Lizi · 流动的记忆

黑色沉浸背景中的三维粒子照片：主体保留照片细节，边缘持续消散、流动和形变。鼠标外圈产生吸引，近处产生排斥；按住拖拽可以从不同角度观看。

## 本地运行

安装 Node.js 18 或更高版本，在项目目录执行：

```bash
npm start
```

打开终端显示的地址，默认是 `http://127.0.0.1:3000`。项目没有第三方运行依赖，无需执行 `npm install`。

也可以用任意静态 HTTP 服务打开项目，例如：

```bash
python -m http.server 3000
```

请通过 HTTP 服务访问；直接双击 HTML 文件可能受到浏览器本地图片纹理限制。

## 操作

- 鼠标移动：外圈向指针吸引，内圈向外排斥。
- 鼠标按住拖拽：旋转三维视角；触摸设备支持单指拖拽。
- 滚轮：缩放。也可使用“动态”面板中的画面缩放。
- 视角按钮：左转、右转、俯视和恢复正面。
- “更换照片”：选择本地图片，图片在当前浏览器中处理。
- “暂停流动”：暂停自动形变，保留鼠标交互。
- “参数”：展开或收起调节面板。

## 参数面板

| 分类 | 参数 |
| --- | --- |
| 画面 | 主体清晰度、粒子密度、粒子大小、边缘消散、画面亮度 |
| 动态 | 流动速度、流动幅度、三维起伏、画面缩放 |
| 鼠标 | 影响范围、吸引强度、排斥强度、复原时间、拖拽灵敏度 |

内置“清晰流动”“柔软薄纱”“强烈牵引”三种起始风格，也可以恢复默认参数。

## 实现与范围

使用原生 JavaScript、WebGL 和自定义 GLSL 着色器。连续图像表面和粒子共用形变规则，以兼顾照片辨识度与粒子表现；细节与颗粒感的平衡可以调节。

三维效果是照片薄片及其粒子的空间形变，未对照片里的真实场景进行三维重建。当前版本专注视觉交互，没有接入语音聊天、日记生成或云端存储。

默认示例来自用户提供的参考视频画面。可通过“更换照片”使用自己的原图。项目不需要 API 密钥，选取的照片不会被此页面上传。

默认持续流动；如果系统开启“减少动态效果”，会暂停自动流动，可自行点击继续。
